## 首次使用

1. 按 [部署指南](deployment.md) 启动服务，打开 `/admin` 设置管理员密码。
2. 在“监控管理”创建监控项，等待首次检测。
3. 在“状态面板”创建面板、展示分组并添加监控，选择默认面板。
4. 访客通过 `/status/<面板路径>` 查看状态，站点根路径按入口设置跳转。

管理员使用密码登录，不需要用户名。没有通用初始密码，首次初始化应在可信环境完成。

## 监控管理

列表顶部显示全部、正常、故障和停用数量。可按名称、目标、标签或分组搜索，并结合分组和状态筛选；按 `Ctrl+K`（macOS 为 `⌘K`）可定位搜索框。

监控编辑弹窗按监控类型显示适用页签。HTTP 提供“HTTP 选项”和“身份验证”，WebSocket 提供“WebSocket 设置”；各类型共用“基本信息”和“检测设置”。切换页签会保留未保存内容，保存时若必填项未填写，会自动定位对应页签和字段。

### 复制创建

点击监控列表行右侧或详情页的“复制创建”，打开预填配置的创建弹窗。名称默认追加“（副本）”，接近长度上限时会截短原名称，为后缀预留空间。

副本保留原监控的类型、目标、分组、标签、检测设置、启停状态，以及 HTTP 请求、认证或 WebSocket 配置。调整后点击“保存”，创建独立监控；取消则不创建。新监控不继承原项的心跳、日志或状态面板关联，需要单独加入状态面板。

### 类型与目标

| 类型 | 目标与检测方式 |
| --- | --- |
| HTTP/HTTPS | 填写完整 URL，按响应状态码判断；HTTPS 同时记录连接和证书信息 |
| WebSocket | 填写完整 WS/WSS URL，验证握手，可进一步发送 Ping 并等待匹配的 Pong |
| TCP 端口 | 填写主机名或 IP、端口，检查能否建立连接 |
| Ping | 填写主机名或 IP，通过系统 Ping 检查网络连通性 |
| DNS | 填写域名、记录类型，可指定服务器及期望解析结果 |

DNS 支持 A、AAAA、CNAME、MX、NS、TXT。服务器留空使用系统 DNS，指定时使用 `IP:端口`；期望结果留空时只检查解析是否成功，填写后精确匹配任一结果。

### WebSocket 检测

目标填写 `ws://example.com/ws` 或 `wss://example.com/ws`，可带业务路径和查询参数，不允许嵌入账户密码或片段。默认使用握手检测，验证 HTTP/1.1 Upgrade 响应和握手校验值后即成功；“握手 + Ping/Pong”还会发送随机 Ping，并等待内容匹配的 Pong。普通业务消息或不匹配的 Pong 不算成功，单条业务消息超过 64 KiB 时本次心跳检测失败。

每次检测建立新连接，结束后关闭。连接、TLS 握手、协议升级及可选心跳均受同一次尝试的整体超时限制，不跟随重定向。响应延迟记录整次检测耗时；WSS 始终校验证书，并单独记录 TLS 握手耗时和证书信息。Ping/Pong 用于确认协议连接可响应，不验证业务消息处理结果。

“WebSocket 设置”支持可选 Origin、子协议、自定义请求头和指定连接 IP。Origin 使用不含路径、参数或凭据的 HTTP/HTTPS 来源，留空不发送。子协议用英文逗号分隔，最多 16 项，按填写顺序请求协商，服务端也可能不选择子协议。请求头使用字符串值的 JSON 对象，支持 Authorization、Cookie 和 Host；Upgrade、Connection 和 Sec-WebSocket-* 由系统管理。

指定连接 IP 仅替换目标的连接地址，保留 URL、Host 和 WSS 的 SNI、证书域名校验，并直接连接目标；留空时遵循 DNS 和环境代理。公开状态页只展示主机和端口，路径、查询参数、请求头和专属配置均保留在后台；开启隐藏地址后连主机和端口也不公开。

### 通用配置

| 配置 | 行为 |
| --- | --- |
| 显示名称 | 在后台与公开面板显示 |
| 心跳间隔 | 每次完整检测结束后等待的秒数，范围 5～86400 |
| 重试次数 | 失败后额外尝试次数，0～10 |
| 心跳重试间隔 | 失败重试之间等待 1～3600 秒 |
| 请求超时 | 每次尝试上限 1～120 秒 |
| 反转模式 | 目标不可访问视为正常，可访问视为故障 |
| 描述与标签 | 用于说明和查找；加入公开面板后也会公开显示 |
| 后台分组 | 选择监控所属的树形分组 |
| 在状态页隐藏地址 | 公开接口省略地址，后台仍保留完整目标 |

启用后立即检测。失败时按配置重试，重试耗尽后才记录最终故障。停用会停止后续检测，并取消正在进行的请求及重试等待；重新启用后恢复。

### 响应延迟图表

在监控详情查看连接参数、心跳和监控日志。状态改变及故障生成日志，状态不变的正常检测只写入心跳。

心跳条下方的“响应延迟”图表支持 `1h`、`3h`、`6h`、`12h`、`24h`、`3d`、`1w` 七档时间范围，默认 `24h`，每 60 秒自动刷新。切换范围会独立查询该时段的历史，下方历史表格的分页不改变图表范围。

曲线最多显示 480 个时间段的平均延迟，竖线保留各段成功检测的最小值、最大值，含故障的时间段标红，无数据处断线。顶部平均值、P95 和最大值根据该时段内全部成功检测的有效延迟计算；故障次数统计全部失败检测。支持指针、触摸和键盘查看各段的时间、检测次数、故障次数和延迟。查询受系统历史保留天数限制，超过保留范围时显示提示。

图表中的响应延迟为整次检测耗时。连接信息中的 TLS 握手耗时单独记录，两者含义不同。一个时间段只有一次有效检测时，平均值、最小值和最大值相同属于正常情况。

| 操作 | 影响 |
| --- | --- |
| 清空心跳 | 仅删除当前监控的心跳，相关统计重新计算 |
| 清空日志 | 仅删除当前监控的监控日志 |

## HTTP 请求与验证

### 协议、重定向与状态码

| 配置 | 说明 |
| --- | --- |
| HTTP/1.1 | 仅使用 HTTP/1.1，不协商 HTTP/2 或 HTTP/3 |
| HTTP/2（h2） | 仅使用 HTTP/2；HTTPS 通过 ALPN 协商，明文 HTTP 需要服务端支持 h2c，不降级到 HTTP/1.1 |
| HTTP/3（h3） | 仅使用 HTTP/3，需要 HTTPS 及 UDP 连通，不降级 |
| 自动协商（h2 > h1.1） | HTTPS 优先协商 HTTP/2，否则使用 HTTP/1.1；明文 HTTP 使用 HTTP/1.1 |
| 自动协商（h3 > h2 > h1.1） | 默认模式；HTTPS 先建立 QUIC 连接，连接失败时回退到 HTTP/2 / HTTP/1.1；明文 HTTP 使用 HTTP/1.1 |
| 最大重定向次数 | 0～100，默认 10；0 禁止跟随重定向 |
| 有效状态码 | 支持单码和区间，如 `200-299`、`401`；默认接受 200～399 |
| 指定连接 IP | 可选，填写单个 IPv4 或 IPv6，不含方括号、端口或网卡区域标识；留空使用 DNS |

禁止重定向时仍判断当前响应的状态码；若 3xx 在有效范围中，当前响应可以被视为成功。HTTP/3 优先模式不会对已经发出的请求执行协议回退重发。

已有监控明确选择的协议模式保持不变；新建监控或未指定协议时默认使用 h3 > h2 > h1.1。使用环境代理时，两种自动模式均通过 TCP 协商 h2 > h1.1，手动 HTTP/3 不支持该代理。指定连接 IP 的目标直接连接。

指定连接 IP 后，目标地址仍填写域名 URL。例如，目标为 `https://api.example.com/health`，指定 IP 为 `192.168.0.88`，检测会直接连接该 IP，默认 Host、TLS SNI 和证书域名校验仍使用 `api.example.com`。端口取自目标 URL，支持 HTTP/1.1、HTTP/2 和 HTTP/3。

覆盖仅对原目标主机生效，同主机重定向继续使用指定 IP，跳转到其他主机后恢复正常解析。指定 IP 的主机直连，不使用环境代理；其他主机和 OAuth2 令牌请求仍按原规则处理。该配置仅保存在当前监控，不修改系统 DNS 或 hosts，也不通过公开接口返回。

### 请求内容

“忽略 HTTPS 站点的 TLS/SSL 错误”默认关闭。开启后，仅当前监控跳过检测目标的证书链、有效期与域名校验；标准 HTTPS 和 HTTP/3 均生效，OAuth2 令牌请求仍校验证书。

支持 GET、POST、HEAD、PUT、PATCH、DELETE、OPTIONS、TRACE 和 CONNECT。请求体编码支持 JSON、URL 编码表单、XML、纯文本；JSON 检查语法，表单按 `key=value&key2=value2` 填写，XML 和纯文本按原文发送。

请求头填写字符串值的 JSON 对象，例如：

```json
{
  "Accept": "application/json",
  "X-Monitor": "UptimeNest"
}
```

支持自定义 Host；Content-Length、Transfer-Encoding、Trailer 由系统管理。单项 User-Agent 可以覆盖全局配置。跨来源重定向不转发自定义请求头和验证凭据。

### 验证方式

| 方式 | 填写内容 |
| --- | --- |
| 无 | 不额外附加验证 |
| HTTP 基础身份验证 | 用户名与密码 |
| OAuth2 | Token URL、Client ID、Client Secret，可选 Scope；使用客户端凭据流程 |
| mTLS | PEM 客户端证书及未加密私钥，可选附加服务端 CA |

OAuth2 每次检测获取 Token，获取过程包含在检测超时内。mTLS 保留系统信任及服务端证书校验，拒绝跨来源重定向。凭据保存在配置数据库中，公开接口与心跳记录不包含这些请求配置。

## 连接信息与统计

HTTPS 显示 TLS/HTTP 版本、握手耗时、证书剩余有效期及颁发者组织（O）。组织取自站点证书 Issuer 的 O 字段，缺失时省略，不使用 CN 或根证书名称代替。

展开详情可查看实际协商的密钥交换机制和完整加密套件名。实际使用 HTTP/3 时额外显示 QUIC 版本和 0-RTT 使用情况；其他协议不显示。当前不主动启用 0-RTT，没有启用开关。

| 显示 | 计算方式 |
| --- | --- |
| 公开与后台心跳条 | 条宽和间距固定，按可用宽度显示最新检测；按时间从早到晚，记录不足时在左侧灰色补齐 |
| 单项可用率 | 近 24 小时最终心跳中正常记录的比例 |
| 平均响应时间 | 近 24 小时正常检测的平均响应时间 |
| 面板可用率 | 有数据监控的可用率均值 |
| 面板平均响应时间 | 各项正常检测均值的平均值，不包含反转监控 |

心跳条不表示固定天数。没有数据时显示无数据，不填充为 100%。HTTP 总耗时包含少量响应体读取，Ping 耗时包含系统命令执行开销。

## 监控分组

后台分组支持父子树形结构，父组状态汇总整个子树。可以展开折叠、创建子分组、修改父级，并按分组或名称查找监控。

分组操作统一放在“监控管理”。顶部“创建分组”用于新增顶级分组。分组行右侧的“+”用于添加监控，弹窗预选当前分组；“文件夹+”用于创建子分组。其余操作用于编辑名称或父级、删除分组。

没有监控的空分组也会显示，可按名称搜索或通过分组筛选找到。选择具体监控状态时，只显示有匹配监控的分组。旧地址 `/admin/groups` 自动跳转到 `/admin/monitors`。

- 一个监控属于一个后台分组，也可以保持未分组。
- 分组名称全局唯一，父级不能选自身或子孙。
- 删除后台分组后，直属监控移至未分组，子分组上移一级；监控及历史保留。
- 后台分组调整不改变各个状态面板的独立展示分组。

## 状态面板

每个面板有独立名称、描述和唯一访问路径，可设置一个默认面板。后台入口设置为状态页时，访问根路径跳转到默认面板。

状态汇总将停用的监控项视为正常。其余监控正常或全部停用时，统一显示“所有系统运行正常”，不显示停用补充说明；故障和等待检测结果仍按实际状态展示。

横幅网格从上向下渐隐。每项可用率仅显示百分比，悬停说明为该监控的近 24 小时可用率；心跳条仍按检测次数排列。监控类型标签使用蓝色；证书剩余时间、签发商使用绿色。TLS 1.2、1.3 使用绿色，其他 TLS 版本使用黄色。HTTP/1.x 使用灰色，HTTP/2 使用青蓝色，HTTP/3 使用紫色；常规延迟使用中性色。证书不足 30 天时为琥珀色，已过期时为红色。延迟标签只显示数值，悬停提示说明为 TLS 握手耗时；仅在管理员启用提醒阈值且耗时超过阈值时使用琥珀色。

状态点正常时缓慢呼吸，故障时加快脉冲，离屏或页面隐藏时暂停。竖线首次进入可视区域后从左至右显示，数据刷新不重复播放；悬停或键盘聚焦时显示检测提示。数值变化时有短暂过渡，新故障行的红线从上向下展开，背景先渐亮再淡出。

展开详情时显示近期检测的延迟曲线和连接参数。状态页每 30 秒刷新，刷新图标与倒计时同步。页面隐藏时暂停刷新计时，重新可见且已过期时刷新一次。

请求超过 150 ms 时才显示对应布局的静态骨架屏，数据返回后立即替换。保存、删除后显示右下角提示；切换监控编辑页签时保留未保存内容。

动效跟随操作系统的“减少动态效果”设置，网站内没有单独开关。开启后停止动效，保留状态颜色、提示和数据刷新。Windows 11 可在“设置 → 辅助功能 → 视觉效果”中关闭“动画效果”。

点击监控名称可展开响应延迟历史图表与连接详情。图表直接使用当前接口返回的近期心跳，按实际检测时间排列，不代表固定 24 小时，也不提供额外时间范围切换。平均值、P95 和最大值仅统计这些记录中成功检测的有效延迟。

缺少可确认响应延迟的故障记录显示为红色背景区段并断开曲线；已识别的异常响应保留延迟并用红线、红点表示，超时用三角标记，恢复点为空心。区段边界取相邻记录的时间中点，仅表达采样覆盖范围；标注起止时间是首末故障记录的实际检测时间，不代表精确故障持续时长。可移动指针、触摸或聚焦后使用方向键、Home 和 End 查看记录；提示位于曲线上方，不遮挡数据点。页面不绘制说明图例。

“面板标题”替换状态页左上角的名称，最多 200 个字符；留空使用全局站点名称，不额外添加标题行。浏览器标签页标题统一使用“系统设置”中的站点名称，不提供面板单独配置。已指定的页脚版权文字不随站点名称改变。

在面板编辑中创建展示分组，逐组添加监控。分组和组内监控都可通过拖拽或上／下移按钮排序，也可把监控移动到另一个展示分组。一个监控在同一面板内不重复，可加入不同面板。

按住六点手柄拖动时，整行监控或整个分组跟随指针，相邻项实时让位；监控也可拖入空分组。靠近编辑区域上下边缘会自动滚动，底部触发区域位于固定操作栏上方。松开后更新草稿，点击“保存”才写入配置；手机支持触屏拖动，减少动态效果设置下取消让位动画，保留拖动反馈和按钮排序。

| 操作 | 行为 |
| --- | --- |
| 移除展示分组或监控 | 仅从当前面板移除展示，保留监控与历史 |
| 保留空展示分组 | 后台可保存，公开页面不显示 |
| 调整后台监控分组 | 不改变面板名称、分组或顺序 |
| 删除监控 | 从所有面板移除对应引用 |
| 删除默认面板 | 由剩余首个面板递补为默认 |

所有面板均为公开展示面板。显示名称、描述和标签会公开；默认展示主机名/IP 及端口，可在单项监控编辑中隐藏。完整 URL 路径、查询参数、DNS 服务器、请求头和验证凭据不通过访客接口返回。

## 系统设置

| 设置 | 行为 |
| --- | --- |
| 站点名称 | 默认 `UptimeNest`，用于前后台品牌与所有页面的浏览器标题，最多 100 个字符 |
| 显示时区 | 下拉选择常用城市或其他 IANA 时区；新安装默认 `Asia/Singapore`，影响界面时间显示，已保存的设置保留 |
| 入口页面 | 选择默认状态面板或管理后台 |
| 界面语言 | 支持 English 和简体中文，新安装默认英语；保存后应用于管理后台及公开页面，已有语言选择保留 |
| 主题 | 默认浅色，手动切换浅色／深色，保存在当前浏览器 |
| User-Agent | 应用于 HTTP/HTTPS，留空使用 `UptimeNest` |
| TLS 握手延迟提醒阈值 | 0～120000 ms 的整数，默认 0（关闭）；只控制状态页 TLS 握手标签的提醒颜色，不改变监控状态 |
| 当前 IP | 只读，显示按已保存可信代理规则识别的客户端 IP，与登录限流使用的地址一致 |
| 可信代理 IP / CIDR | 每行一个地址或网段，最多 100 项；仅接受来自可信代理的转发头，留空按连接来源识别 |
| 历史保留期限 | 1～3650 天，新安装默认 30 天；已保存期限保留 |
| 清理旧数据 | 按已保存期限删除过期心跳和日志 |

应用启动时及每小时自动清理过期历史，也可以手动清理。更改期限后先保存再执行手动清理；清理不删除监控配置，历史统计随剩余数据更新。

## 账户设置

在“账户设置”输入当前密码和新密码。密码非空、UTF-8 编码后最多 72 字节，不强制大小写、数字或特殊字符组合。

登录会话有效期 7 天，修改密码后撤销其他会话。HTTPS Cookie 由部署环境变量控制，见 [启动参数](deployment.md#启动参数)。
