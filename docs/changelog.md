# 更新记录

[文档中心](README.md) · [下载版本](https://github.com/Qwerto107/UptimeNest/releases) · [发布流程](releasing.md)

## v0.4.0 · 2026-10-25

- 访问安全设置增加只读的当前客户端 IP，与登录限流共用可信代理解析规则，保存设置后更新。
- 精简公开心跳历史：正常记录仅返回时间、状态与延迟，最新连接详情继续由 `latest` 提供；可识别的故障仅附带脱敏分类和可选 HTTP 状态码。
- 状态页展开详情时显示延迟历史图表，复用原有返回范围，提供成功检测的平均值、P95 和最大值，支持中英文、深浅色、手机及指针、触摸、键盘查看。
- 故障图表显示红色区段、异常响应曲线、超时与恢复标记；未知原因按通用故障展示，不公开原始诊断，不绘制底部图例。
- 悬浮提示放入曲线上方的独立区域，避免遮挡数据点，窄屏下减少默认区段标注以避免重叠。

## v0.3.0 · 2026-10-25

- 将下拉框统一为项目主题组件，支持中英文、键盘选择、触摸及分组选项。
- 增加英语界面，支持在系统设置中切换英语或简体中文；新安装及缺少语言配置时默认英语，保留已有语言选择。
- 将后台分组管理合并到监控列表，支持直接创建、编辑、删除及创建子分组，搜索和分组筛选支持空分组；旧分组页面自动跳转。
- 登录按客户端 IP 限流；系统设置支持可信代理 IP / CIDR，仅接受可信代理转发的客户端地址。
- 管理页与状态页增加分页，保留全局搜索、筛选和统计；监控详情改为按需查询单项。
- 批量查询监控汇总与近期心跳，公开面板响应增加 3 秒有界缓存，减少重复查询；复用日期格式化器与心跳标签。
- 历史记录使用时间与 ID 联合分页，避免同时间记录遗漏；过期历史分批清理，支持取消后继续。
- 修复点击状态页标题返回入口时短暂显示其他标题栏的问题。
- 状态页管理入口改为与主题切换一致的图标按钮；监控详情增加展开、收起动画，并遵循减少动态效果设置。
- 普通界面文字使用默认鼠标指针，输入框保留文本光标，文字仍可选择和复制；统一设置分区编号。

## v0.2.0 · 2026-10-25

- 状态面板汇总将停用监控视为正常；其余监控正常或全部停用时，统一显示“所有系统运行正常”，不显示停用补充说明。
- 面板编辑支持整项跟随指针、实时让位、跨组拖动及编辑区域边缘滚动，兼容触屏和减少动态效果设置。
- 默认检测 User-Agent 改为 `UptimeNest`；新安装历史保留期限改为 30 天，保留已有设置。
- HTTP/HTTPS 监控增加默认关闭的“忽略 HTTPS 站点的 TLS/SSL 错误”，同时作用于 HTTP/3 检测。
- 显示时区改为下拉选择，新安装默认新加坡；提供常用城市及浏览器支持的 IANA 时区，保留旧配置中的时区别名。
- 支持全局自定义站点名称，面板标题替换状态页左上角名称，浏览器标题统一使用全局站点名称。
- 前后台心跳条改为固定条宽与间距，按容器宽度调整显示数量，并按需补取最新历史。
- 按 Pulse Status 设计重写管理后台，统一浅色／深色主题、紧凑导航、列表、设置与登录界面；监控编辑改为分项页签，并适配手机布局。
- 按文档中心、使用、部署、开发、API、二进制与发布流程重新整理项目文档。
- 更新浅色／深色状态页、监控、分组、面板及设置的界面预览，使用独立演示数据。
- Compose 改为直接拉取统一镜像，使用宿主机 `./data`、只读根目录、临时目录及显式健康检查；旧命名卷迁移见 [部署指南](deployment.md#升级与回退)。

## v0.1.0 · 2026-10-24

- 提供 HTTP/HTTPS、TCP 端口、Ping 和 DNS 监控，支持间隔、超时、失败重试、反转及启停。
- HTTP 支持 HTTP/3 优先回退或仅 HTTP/3、重定向限制、有效状态码、请求方法、请求体与请求头；支持 Basic、OAuth2 客户端凭据及 mTLS。
- 展示 TLS/HTTP 版本、握手耗时、证书剩余有效期及签发者组织；详情包含密钥交换及加密套件，HTTP/3 额外显示 QUIC 版本和实际 0-RTT 使用情况。
- 支持后台树形分组与状态面板独立展示分组、多面板路径、默认面板、拖拽及按钮排序、按项隐藏地址。
- 支持心跳与日志查询、按项独立清空、历史保留期限和自动／手动过期清理。
- 提供简体中文、浅色／深色主题、显示时区、入口页面、全局 User-Agent 与管理员密码管理。
- 支持 SQLite 或 PostgreSQL，提供内嵌前端的七平台程序、三架构容器镜像及自动 Release。
